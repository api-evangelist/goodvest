# Goodvest

> Goodvest is a French mission-driven fintech (entreprise à mission, Paris, ORIAS 20007544)
> selling climate-aligned retail savings: an ISR assurance-vie (Goodvie, insured by Generali),
> a euro-fund assurance-vie (Goodlife, insured by Spirica), a Plan Épargne Retraite (PER), a
> minors' contract, a green Livret d'Épargne and a private-management tier (Goodvest First).
> Portfolios are screened against a published seven-filter methodology aligned with the Paris
> Agreement — fossil-fuel exclusion, carbon-footprint and biodiversity analysis — and every
> unit-linked support carries EU SFDR Article 8 or Article 9 disclosures.

## Coverage note for agents

Goodvest publishes **no public API, SDK, webhook surface or developer portal**. There is no
OpenAPI, GraphQL SDL, AsyncAPI, MCP server or A2A agent card on any Goodvest host. The
application backend at `https://api.goodvest.fr` is private (gunicorn; HTTP 404 at root and
on every spec and `/.well-known/` path probed 2026-08-17) and serves only the first-party web
and mobile clients. `https://app.goodvest.fr` is a single-page application that answers HTTP
200 with the same HTML shell for every path, so a 200 from that host is not a document.
Goodvest markets a white-label / "marque grise" partnership to digital platforms, but that is
a commercial conversation with no published technical contract.
